## 四、顺带修掉的一个真 bug（preflight-check 的自我误报）

发布后跑检查时出现 **A2 FAIL**，但报的却是**检查器自己**：`SKILL.md` 和 `run-preflight.js` 里
写了 `"role":"service_role"`、私钥头这些**规则字样本身**，被 A2 抓了。

- **成因**：A2 只扫**被 Git 跟踪**的文件。Day 25 建技能时的三遍检查，技能文件**还没提交**，所以 A2 扫不到自己；
  `d3514fc` 一提交，它就自己撞上自己 —— 一条**假的 FAIL**。
- **修法**：A2 里三条「**特征字样**」比对（私钥头 / `service_role` 标记 / 疑似 JWT）**跳过技能自身目录**；
  最要紧的「**`.env` 真值比对**」**不跳过**，仍全量扫。理由按技能自己的「硬规矩 2」写进了 `SKILL.md`。
- 修完复跑：**PASS 7 / FAIL 0**。
