# Day 27 · 第三方线上试用包（2026-10-13）

> **这份是给斌用的**，不是给测试员看的。
> 目标：请**一位没参与过这个项目的人**，在**他自己的设备**上，把**线上版**的核心流程走一遍。
> 只看一件事：**他卡在哪儿**。他停下的那一步，就是我的 bug。

---

## 一、斌要做的三件事（别的都不用管）

1. 找一位**没参与过这个项目**的人（同事 / 朋友 / 家人，越不懂技术越好）。
2. 把下面「复制这段发给他」**原样**发过去（链接已经填好，不用改）。
3. 他做完后，把**他的话**和**截图**发回来；填进本文最后一节的观察表。

> ⚠️ 全程不要说「你点那里」「这里能补记」——**给了提示就测不出问题了**。
> 他问「这个点哪」，答「你觉得应该点哪？先试试」。

---

## 二、复制这段发给他（原样，别改）

```
帮我试用一个小网站，5 分钟就好 —— 是我自己做的一个「习惯打卡 + 待办」的小页面。

链接：https://habit-board-d0gum6nqu512acc29-1499798330.tcloudbaseapp.com/

⚠️ 打开后如果先跳出一个腾讯云的页面，写着「页面访问提示」之类的，
   点那个「确定访问」按钮进去（这是腾讯云测试域名的一道门，不是我做的页面）。

进去以后你自己随便看看，然后照下面 7 件事做一遍。
不用担心弄坏，这是测试环境，你加的东西随便加。

做的过程中，如果哪一步卡住了、不知道点哪儿：
   别问我，先自己试着找 ——  我要看的正是你"会卡在哪"。
   实在找不到就跳过，并告诉我"我卡在哪了"。
```

## 三、七条任务（分别发给他，一条一条来）

| # | 念的题目（照念，别加词） | 这条在测什么 |
| --- | --- | --- |
| 1 | 「你先打开看看，然后告诉我这是个什么东西、你打算先点哪里。」 | 第一眼是否自解释 |
| 2 | 「加一个习惯，叫『每天喝够 8 杯水』。」 | 新增入口好不好找 |
| 3 | 「今天你已经喝了，把它记成今天做完了。」 | 「完成」这个动作是否唯一 |
| 4 | 「昨天你忘了记，把昨天补上。」 | **补记入口是否暴露（Day 14 真人卡过这里）** |
| 5 | 「这个习惯最近一个月坚持得怎么样？给我个说法。」 | 记录入口 + 口径（今日页点名字弹层） |
| 6 | 「记一件事：晚上给妈打电话。加完再把它删掉。」 | 增删 + 删除确认是否讲得清 |
| 7 | 「页面上还有没有别的地方可以去？你自己找找。」 | 跨页入口（`看板 ↗`）是否被发现 |

**判定「卡住」**（任一条打钩就算，打钩那步就是要修的）：

- [ ] 任务开始后 **15 秒**内没有任何点击动作（只在看、只在滑）
- [ ] 点了一个**跟任务无关**的东西
- [ ] 中途问出「这是干嘛的？」「点在哪儿？」
- [ ] 做完了但**结果不是他要的**（例如以为补的是昨天、实际记成了今天）
- [ ] 完成后**说不出自己刚才做了什么**

## 七、这次跟 Day 14（本地测试）不一样的地方，事先有个数

| | Day 14（本地） | Day 27（线上，这次） |
| --- | --- | --- |
| 怎么给页面 | 发**整个文件夹**的 zip，他自己双击 `index.html` | **只发一个链接**（不用发文件了） |
| 手机能不能用 | ❌ 打不开（本地 html 在手机上不好使） | ✅ **能**，真人可以用手机测 |
| 数据存在哪 | 浏览器本机 | **云端数据库**（他加的习惯是真写进库的） |
| 额外一道门 | 无 | ⚠️ 腾讯云「页面访问提示」，要点「确定访问」 |

> 但真人用浏览器打开**一定会先看到它**。如果他在这里犹豫了，那就是「我没想到的地方」。
