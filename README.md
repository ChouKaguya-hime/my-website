# my-website

我的第一个 GitHub 项目。目前是 Day 6 的状态：需求、**技术方案**和**项目规则**都已经定下来，功能从 Day 7 开始搭建。

## 当前状态

| 文件 | 作用 |
| --- | --- |
| `AGENTS.md` | 项目规则（给 AI 的工作手册）：Day 1 立的沟通/工作规则 + Day 6 追加的边界规则 |
| `index.html` | 占位页，Day 7 会改造成 MVP 页面 |
| `research.md` | 需求研究（Day 3）：3 个类似产品比较 + 本期不做清单 |
| `PRD.md` | 产品需求文档（Day 4）：做什么 / 不做什么 / 怎么算做完了（含 13 条验收标准） |
| `TECH_DESIGN.md` | 技术方案（Day 5）：技术路线 + 数据流图 + 实现期硬约束（T1–T8） |
| `.gitignore` | 忽略规则，确保 `.env` 等本地文件不会被上传 |
| `.env` | 本地环境变量（**已被忽略，不在仓库里**），Day 23 接数据库时启用 |

## 本地预览

直接用浏览器打开 `index.html` 即可，**不需要任何服务器、依赖或构建步骤**。
这是 `TECH_DESIGN.md` 定下来的技术路线，用来满足 PRD 的 AC-1（双击就能打开）和 AC-10（零外部网络请求）。
